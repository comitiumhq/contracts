# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Report them privately to [security@comitium.co](mailto:security@comitium.co). Include the affected contract and deployment, reproduction steps, security impact, and any relevant transaction hashes or proof-of-concept code that does not contain secrets or other users' data.

When researching a vulnerability, do not access funds or data that do not belong to you, disrupt the service, publish credentials, or interact with a live deployment beyond transactions you are authorized to make.
